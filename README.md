## Overview
This repository contains all scripts used in the paper for:
- Data acquisition (pressure taps, load cell, pitot tube)
- Post-processing and error/uncertainty calculation
- Statistical summarization into meta datasets
- Mutual information (MI) analysis
- Predictive modeling (including Bayesian hyperparameter tuning for XGBoost)
- Final model training/testing and performance summarization
- Figure/plot generation
- LaTeX table/text generation

> **Reference data:** Figshare — `https://doi.org/10.6084/m9.figshare.c.8065798` (download all input data to same working directory of this code folder to run the code below)

## 1) Data Acquisition (Wind Tunnel Test Run Code)
**Folder:** `Wind_Tunnel_Test_Run_Code`  
Scripts for collecting wind-tunnel measurement data.

**Inputs**
1. DAQ system connected to all pressure taps and the pitot tube  
2. DAQ system connected to the load cell  
3. Ambient environmental conditions specified in `Testing_Day_Condition`

**Output**

## 2) Converters (Python)
**Tare definition:** *“Tare” is measured with the model powered on and the wind tunnel turned off.*

1. **`Converter_pressure_tap.py`**
   - Converts raw pressure-tap voltages to calibrated pressures  
   - Subtracts the corresponding tare (per channel)  
   - Writes to `Post_Data/.../Tared/` (mirrors raw structure)

2. **`Converter_load_cell.py`**
   - Converts raw 6-axis load-cell voltages to calibrated forces and moments  
   - Subtracts the corresponding tare (per axis)  
   - Writes to `Post_Data/.../Tared/` (mirrors raw structure)

**Notes**
- Intermediate “Test” and “Bias/Tare” outputs are saved to `Post_Data/.../Test` and `Post_Data/.../Bias`  
- Folder structure/filenames are preserved for cross-referencing

## 3) StatsCal (Python)
Computes **true error and statistics** from **time-series** data for both **pressure** and **force**, following: <http://www.metrology.pg.gda.pl/full/2010/M&MS_2010_003.pdf>.

1. **`StatsCal_L_D_stats_csv.py`**
   - Per-sample and aggregate statistics for lift/drag after **subtracting sting aerodynamic effects**  
   - Proper **error propagation**; produces **ΔL/D** summaries  
   - Outputs `*_truestats.csv` into **Tared** folders

2. **`StatsCal_Pressure_stats_csv.py`**
   - Per-sample and aggregate statistics for **pressure** with **error propagation**  
   - Produces **Δp** summaries  
   - Outputs `*_truestats.csv` into **Tared** folders

3. **`StatsCal_polar_force_coefficient_to_csv.py`** → **generates Figure 1b polar data**
   - Recursively collects **tared load-cell files** from **Polar** runs across all AoA  
   - Uses testing-day conditions (`Testing_Day_Condition.csv`) to compute **airspeed** and **Reynolds number**  
   - Computes **CL, CD**, attaches airspeed/Reynolds, **propagates errors**  
   - **Outputs** to `Post_processed_force_coefficient/`:  
     - Per-AoA stats: `Force_coefficient_AoA_*_stats.csv`  
     - Combined CSV: `Force_Coefficients_AoA_All.csv` ← **this is the Figure 1b data file loaded by `Plotter_force_coefficient.py`**

---

## 4) StatsSum (Python)
Collects every `*_truestats.csv` produced by **StatsCal** and **concatenates** them into **meta-summary CSVs**.

1. **`StatsSum_all_force_to_one_csv.py`** → **generates Figure 2b data (load-cell ΔL/D)**
   - Recursively finds force/moment `*_truestats.csv`  
   - Extracts run metadata from folder paths; appends as columns  
   - Writes to `Post_processed_stats_summarized/`:  
     - `L_D_True_Stats_Iter_0.csv`  
     - `L_D_True_Stats_Iter_1.csv` ← **these are the Figure 2b data files loaded by `Plotter_heatmap_from_experiment.py`**

2. **`StatsSum_all_pressure_to_one_csv.py`** → **generates Figure 2c data (pressure Δp)**
   - Recursively finds pressure-tap `*_truestats.csv`  
   - Extracts matching metadata; appends as columns  
   - Writes one CSV **per Iter**: `Pressure_True_Stats_Iter_*.csv` in `Post_processed_stats_summarized/` ← **these are the Figure 2c data files loaded by `Plotter_heatmap_from_experiment.py`**

## 5) RepCheck (Python)
**Script:** `RepCheck_repeatability.py`  
Checks **repeatability** between **Iteration 0** and **Iteration 1**.

- **Method:** Compute **RMSD** for each matching data point across iterations, then normalize by data range to report **NRMSD (%)**  
- **Input:** `Post_processed_stats_summarized/` (from StatsSum scripts)  
- **Output:** Text report of **NRMSD for pressure** and **NRMSD for force**

**Notes**
- NRMSD = RMSD / (max − min), per comparable group/configuration  
- Assumes summarized CSVs contain consistent metadata (e.g., `type_of_run`, `X`, `AoA`, `Iter`)

## 6) Mutual Information (R)
**Script:** `MI_implementation.R` → **generates Figure 3b, 3c, 3d data**  
Quantifies how much information **pressure-set signals** share with **aerodynamic states**.

- **Inputs:** `Post_processed_stats_summarized/L_D_True_Stats_Iter_{0,1}.csv`, `Pressure_True_Stats_Iter_{0,1}.csv`  
- **Outputs** (Iteration 0, in `MI_results/`):  
  - `Individual_MI_results.csv` (+ `_ranked`) ← **Figure 3b data (individual-tap MI) loaded by `Plotter_MI_taps.py`**  
  - `Combination_MI_results.csv` (+ `_ranked`) ← **Figure 3c & 3d data (tap-combination MI) loaded by `Plotter_MI_taps.py`**  
  - Bin-selection diagnostic plot: `MI_results/Plots/SI_Figure_4_MI_Bin_plot.pdf`  
  - Bin-sensitivity sweep (bins 10–32): `bin_*_{combo,individual}_{ranked,unranked}.csv`, `MI_sensitivity_summary.csv`  
- **Outputs** (Iteration 1): mirrored set in `MI_results_iter1/` (files suffixed `_iter1`), plus `Plots/Iter0vsIter1.pdf` bin-comparison plot

**Notes**
- MI with controlled discretization/binning (equal-frequency; optimal bin count auto-selected, results based on 28 bins)  
- Designed to compare across AoA, X, Iter, etc.

## 8) Predictive Model (Python)
XGBoost and simple-model (OLS/Ridge/Lasso/PLS) predictive modeling for formation-flight analysis. The current workflow uses **grouped nested cross-validation**, keyed on `(XPos, YPos, ZPos, AoA)`, so repeated Iter 0 / Iter 1 measurements of the same aerodynamic configuration never split across CV folds. The original single train/test Bayesian-tuned workflow has been superseded by this and moved to `Archive_script/` (see [Appendix C](#appendix-c-archived-scripts)).

### 8.1 `PredModel_delta_pressure_interpolator.py`
- Generates interpolated Δpressure dataset for overfitting sanity checks  
- **Input:** `Post_processed_stats_summarized/Pressure_True_Stats_Iter_1.csv`  
- **Output:** `Predictive_model_data/Interpolated_pressure_data/Pressure_True_Stats_Iter_1_Interpolated.csv`

### 8.2 `PredModel_Grouped_Nested_CV_Bayes_Optimization_HyperP_XGBoost.py` → **generates Figure 4B data**
- Current XGBoost workflow: **5-outer x 5-inner grouped nested CV**, using `GroupKFold` so the inner Bayesian-optimization loop (20 random initializations + 100 iterations) never tunes on data leaked from the held-out outer fold  
- Iterates over all `pressure_combo` x `position_combo` predictor-set combinations (0/2/6/12 pressure taps x None/X/Y/Z/XYZ position deltas)  
- **Inputs**
  - `Post_processed_stats_summarized/L_D_True_Stats_Iter_0.csv`, `L_D_True_Stats_Iter_1.csv`  
  - `Post_processed_stats_summarized/Pressure_True_Stats_Iter_0.csv`, `Pressure_True_Stats_Iter_1.csv`
- **Outputs** (one set per predictor-set combination) written to `Predictive_model_data/Grouped_Nested_CV_XGB/`:
  - `Outer_fold_results_*.csv`, `Best_hyperparameters_*.csv`, `Bayes_search_history_*.csv`  
  - `Summary_metrics_*.csv` ← **these are the Figure 4B data files loaded by `Plotter_heatmap_grouped_nested_cv.py`**

### 8.3 `PredModel_LM_PLS_Ridge_model.py`
- Runs the same grouped 5-fold CV (with inner `GridSearchCV` tuning where applicable) for four simple linear baselines: Linear Regression, Ridge, Lasso, and PLS  
- Uses the same 19 pressure/position predictor-set combinations as **8.2** so model-class comparisons stay aligned  
- **Inputs:** same four `Post_processed_stats_summarized/` CSVs as **8.2**
- **Outputs** written to `Predictive_model_data/Grouped_CV_Simple_Models/`:
  - Per-model/predictor-set fold results and summaries, plus combined ranking/pivot tables (`Combined_summary_metrics.csv`, `Predictor_set_ranking_by_model.csv`, `Predictor_set_rmse_pivot_table.csv`)

### 8.4 `PredModel_XGBoost_robustness_testing.py` → **trains the cross-iteration models behind Figures 4C & 4D**
- Re-trains XGBoost on the **full Iter 0** dataset and tests on the **full Iter 1** dataset across 5 fixed seeds, to check seed sensitivity outside of the CV splits  
- Hyperparameters are loaded from **outer fold 1** (a fixed, non-selected fold) of **8.2**'s results, to avoid any impression of cherry-picking the best fold  
- **Inputs:** same four summary CSVs as **8.2**, plus `Best_hyperparameters_*.csv` from **8.2**'s output folder
- **Outputs** written to `Predictive_model_data/Iter0_Iter1_Robustness_XGB/`:
  - Per-seed RMSE/MAE/R² and saved model files (`.json`), plus combined summaries across all predictor sets

### 8.5 `PredModel_latency_test.py` → **generates Figure 4C & 4D data**
- Benchmarks **single-sample inference latency** for XGBoost and the four simple models (loads the saved XGBoost models from **8.4**; refits simple models using **8.3**'s tuned settings if no saved model is found)  
- Reports mean/median/min/max latency (ms) and predictions-per-second per model and predictor set, plus latency differences relative to the fastest model and to XGBoost  
- **Inputs:** `Predictive_model_data/Iter0_Iter1_Robustness_XGB/` (**8.4**), `Predictive_model_data/Grouped_CV_Simple_Models/` (**8.3**)
- **Outputs** written to `Predictive_model_data/Latency_Benchmark/`:
  - `Latency_results_detailed.csv`, `Latency_results_ranked.csv`, `Latency_difference_by_model.csv`, `Latency_difference_by_predictor_set.csv`  
  - Per-predictor-set raw prediction tables in `Raw_prediction_tables/` (`Raw_predictions_*.csv`) ← **these cross-iteration per-sample predictions (Iter 0-trained models from 8.4 evaluated on Iter 1) are the Figure 4C & 4D data files loaded by `Plotter_XGBoost_predicted_heatmap_error_map.py`**

### 8.6 `PredModel_RMSE_summary_each_model_to_csv.py`
- Loads files from the archived `PredModel_final_train_and_test.py` workflow and selects the **best RMSE** across five fixed-seed models  
- **Input:** Prediction CSVs from the archived workflow (see [Appendix C](#appendix-c-archived-scripts))  
- **Output:** One CSV with the best RMSE for each model

## Appendix A. Notation & Definitions
- **ΔL/D (delta L/D):** Change in lift-to-drag metric (per StatsCal definitions)  
- **Δp (delta pressure):** Change in measured pressure  
- **Iter:** Iteration index (e.g., 0 or 1)  
- **NRMSD:** Normalized root-mean-square deviation = RMSD / (max − min)
